## Про проєкт

NEOwatch — платформа для спостереження за космосом двома шляхами:

- **Сайт** — публічний дашборд і десятки сторінок про Сонячну систему, глибокий
  космос та новини астрономії, з інтерактивними картами супутників у реальному
  часі.
- **Telegram-бот** — персональні сповіщення (проходження МКС, запуски, фото дня,
  небезпечні астероїди, спалахи, магнітні бурі) під конкретну локацію
  користувача.

Обидва інтерфейси — **білінгвальні (🇺🇦 українська / 🇬🇧 англійська)** й живуть
**в одному процесі** (FastAPI + uvicorn піднімає і сайт, і бота на спільному
event loop'і). Якщо база даних або токен бота недоступні — сайт все одно
працює (погода/небо/запуски не залежать від БД).

## 🌐 Сайт

React SPA (`my-app/`) з мовними URL-префіксами `/ua/...` та `/en/...`
(перекладені slug'и), SSR-подібним server-side SEO (title/canonical/hreflang/
OG/JSON-LD інжектяться на бекенді) та опційним headless-Chrome prerendering
для соцмереж/пошукових ботів.

| Розділ | Що показує |
|---|---|
| 🏠 Головна | «Сьогодні вночі»: МКС, планети, метеори, Місяць, погода — жива sky-dome радар-панель |
| 🛰️ МКС | Положення, наступні проходження, наземний трек, зона видимості |
| 🛰️ Супутники | Інтерактивна карта Celestrak-груп (Starlink, візуальні, станції, погодні, GPS, геостаціонарні, аматорські…) з live SGP4-пропагацією прямо в браузері |
| 🌌 Космопогода | Kp-індекс, сонячний вітер, Bz, рентген GOES, шторм-банер, графіки Chart.js |
| ⭐ Сузір'я | Зоряна карта на основі каталогу HYG |
| 🔭 MAST | Криві блиску та знімки Hubble/JWST (ізольований subprocess) |
| ☄️ Метеорні потоки | Повний календар: пік, ZHR, радіант, найкращий час спостереження |
| 🌑 Астероїди | Найближчі зближення NEO, дистанції в LD |
| 📅 Події | Затемнення, з'єднання планет, тижневий дайджест (ретроградні рухи, суперМісяці) |
| 🌃 Темне небо | Прогноз умов спостереження, світлове забруднення |
| 🚀 Запуски | Найближчі старти (Launch Library 2) |
| 📰 Новини | Архів новин космонавтики з кількох джерел, перекладений |
| 🌌 Дальній космос | Космічне сміття, гамма-спалахи (GRB), Voyager 1/2 |
| ☄️ Комети | Видимі зараз комети |
| 🪐 Екзопланети | Каталог підтверджених екзопланет |
| 🌌 Галерея APOD | Дзеркальований архів «Фото дня» NASA |
| 🌌 Галактики | 12 обраних галактик: тип, зсув (NED), фотогалерея |
| 🪐 Планетарій | Хаб + окрема сторінка на кожну планету (Mercury→Neptune); Jupiter/Saturn/Uranus/Neptune мають fullscreen PixiJS-переглядач системи супутників |
| 🌍 3D Сонячна система | Інтерактивна 3D-сцена (three.js / React Three Fiber) |

Локація визначається через `localStorage`, з picker'ом на базі геокодингу;
браузерні push-сповіщення (Web Push / VAPID) працюють незалежно від Telegram.

## 🤖 Telegram-бот

Меню кнопок, вкладене за темами:

```
Головне меню
├── 🛰️ МКС / супутники      → зараз, проходження, екіпаж, Starlink
├── 🚀 Запуски ракет
├── 🌑 Астероїди (NEO)
├── 🌌 Фото дня (APOD)
├── 🌌 Космопогода           → сонячна погода, полярне сяйво, Марс
├── 🔭 Небесні події          → метеори, астро-події, Місяць, планети,
│                              марсоходи, тижневий дайджест, факт дня,
│                              дальній космос (Voyager, сміття, GRB)
└── ⚙️ Налаштування          → локація, тихі години, фільтр яскравості МКС,
                               підписки, мова (🇺🇦/🇬🇧)
```

Локація вказується текстом (назва міста → геокодинг через OpenStreetMap
Nominatim); країна визначається по bounding box'у для локального форматування.

## 🔔 Автоматичні сповіщення

| Час | Подія | Тип |
|---|---|---|
| 09:00 | Фото дня (APOD) + поповнення архіву | Щоденно |
| 10:00 | Дайджест космічних новин + астроподії | Щоденно |
| 22:00 | Нагадування про метеорні потоки | За день до піку + в день піку |
| Кожні 10 хв | Проходження МКС | Реальний час |
| Кожні 5 хв | Запуски ракет (−10…+5 хв від старту) | Реальний час |
| Щогодини | Небезпечні астероїди, сонячні спалахи, магнітні бурі | Реальний час |
| Кожні 30 хв | Гамма-спалахи (GRB) | Реальний час |
| Кожні 2 год | Оновлення архіву новин (фоново) | Background |
| Щотижня (Пн 03:00) | Оновлення каталогу галактик з NED (фоново) | Background |

Дедублікація — через БД для кожного типу сповіщень. «Тихі години» та фільтр
яскравості МКС налаштовуються персонально в `⚙️ Налаштування`.

## Технології

**Бекенд** — Python, FastAPI + uvicorn (спільний event loop із ботом),
`python-telegram-bot`, MySQL (`mysql-connector-python`), `skyfield`
(офлайн-ефемериди), `lightkurve`/`astroquery` (MAST, ізольовано в subprocess),
`pywebpush` (Web Push), опційно Playwright (SEO-prerendering).

**Фронтенд** — React 19, `react-router-dom` v7, `react-i18next`, `zustand`,
`chart.js`, Leaflet + `satellite.js` (карти супутників, SGP4 у браузері),
`pixi.js` (системи супутників планет), `three` + `@react-three/fiber`/`drei`
(3D Сонячна система).

**Дані** — NASA (NEO, APOD, InSight), N2YO, Launch Library 2, NOAA SWPC,
Celestrak (TLE), NASA GCN Circulars, NED, MAST, Mars Vista API, OpenStreetMap
Nominatim, HYG-каталог зірок.

## 🚀 Швидкий старт

```bash
git clone <repo> neowatch && cd neowatch

# Python-залежності
pip install -r requirements.txt
cp .env.example .env   # заповни ключі API та MySQL

# Обов'язково: збери React SPA — без цього web.app не підніметься
cd my-app && npm install && npm run build && cd ..

# Сайт + бот в одному процесі
python3 -m uvicorn web.app:app --host 0.0.0.0 --port 8000

# Розробка сайту без бота/БД
BOT_TOKEN= python3 -m uvicorn web.app:app --port 8000

# Гаряча перезагрузка фронтенду (проксі /api → :8000)
cd my-app && npm start

# Лише бот, без сайту (легасі-режим)
python3 bot.py
```

Повна інструкція з production-деплою (systemd, MySQL, nginx, prerendering) —
у [`DEPLOY.md`](DEPLOY.md).

## 📁 Структура проєкту

```
NEOwatchBot/
├── bot.py                 # Легасі bot-only entrypoint
├── config.py               # Ключі API, константи
├── database.py              # MySQL: users, notifications, новини, галактики, APOD-архів…
├── handlers/                # Telegram-хендлери (commands / callbacks / messages)
├── services/                 # Обгортки над зовнішніми API (планети, метеори, MAST…)
├── parsers/                   # RSS/HTML-парсери новин
├── utils/                      # i18n, клавіатури, перекладач, константи
├── web/                         # FastAPI: app.py, api.py, data.py, seo.py, cache.py…
├── my-app/                       # React SPA (сайт), збирається в my-app/build/
├── site/                          # (застаріле — замінено на my-app/)
├── data/                           # Runtime-дані (gitignored): TLE-кеш, зображення, ефемериди
└── scripts/                        # Допоміжні скрипти (генерація VAPID-ключів тощо)
```

Детальний опис архітектури, ендпоінтів API та таблиць БД — у
[`CLAUDE.md`](CLAUDE.md).
