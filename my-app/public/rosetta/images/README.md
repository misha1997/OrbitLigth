# Rosetta images

Official ESA observations, resized to at most 1600 px and encoded as JPEG.
Gallery thumbnails use CSS cover cropping; the lightbox presents the full frame.

- `comet.jpg`: ESA/Rosetta/NAVCAM, CC BY-SA 3.0 IGO. [19 September 2014 mosaic](https://www.esa.int/ESA_Multimedia/Images/2014/09/Comet_on_19_September_2014_NavCam). [Licence](https://creativecommons.org/licenses/by-sa/3.0/igo/).
- `philae.jpg`: Main image and lander inset: ESA/Rosetta/MPS for OSIRIS Team MPS/UPD/LAM/IAA/SSO/INTA/UPM/DASP/IDA; context: ESA/Rosetta/NavCam, CC BY-SA 3.0 IGO. [Original annotated composite and ESA Standard Licence](https://www.esa.int/ESA_Multimedia/Images/2016/09/Philae_found).
- `jets.jpg`: ESA/Rosetta/MPS for OSIRIS Team MPS/UPD/LAM/IAA/SSO/INTA/UPM/DASP/IDA. [Original three-frame sequence and ESA Standard Licence](https://www.esa.int/ESA_Multimedia/Images/2015/08/Approaching_perihelion).
